# SURUSHI SOFTWARE - update feed

Acest repo public contine **doar update-uri** pentru SURUSHI SOFTWARE (Releases).
Aplicatia completa / installerul NU se publica aici.

Fiecare release contine:
- `SurushiSoftware-update-<versiune>.zip` - fisierele actualizate
- `latest.json` - versiunea si hash-ul SHA256 al pachetului

Aplicatia verifica singura ultimul release si se actualizeaza la repornire.
